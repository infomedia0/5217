5217 — for Apple silicon Macs
Version 2.4.7 · Requires macOS 13 Ventura or later

INSTALL
1. Open 5217-v2.4.7-Apple-Silicon.dmg.
2. Drag 5217 into the Applications folder beside it.
3. Open 5217 from Applications, then eject the disk image.
4. Click Start focus. Allow notifications if macOS asks.

This personal build is locally signed, but is not Apple-notarized.
If macOS blocks it, go to System Settings > Privacy & Security and
use Open Anyway for 5217 after attempting to open it.

UPGRADING
Quit any running copy of 5217, then replace 5217 in Applications
with this version. Your saved timer and session history are retained.

YOUR RHYTHM
Focus for 52 minutes, break for 17 minutes, and repeat automatically.
The countdown shows minutes and seconds. A notification with sound
marks each transition. If system notifications are unavailable, 5217
shows its own small alert and plays a chime instead.

Use Pause to stop the countdown; Resume continues where you left off.
The circular-arrow button resets the current phase and pauses it.
The skip button moves to the next phase without counting a completion.
The sound control turns transition sounds on or off.
Timer > Test Alert & Chime previews the built-in reminder.

The menu bar shows the remaining time and includes the timer controls.
Closing the window keeps the timer running. Choose Quit 5217 to stop
the app; your timer pauses and is saved for your next launch.

Space: Start / pause
Command-P: Start / pause
Command-R: Reset current timer
Command-Right Arrow: Skip to the next phase
Command-0: Show the window
Command-Q: Quit and save

NOTIFICATIONS & SLEEP
Enable 5217 in System Settings > Notifications for system banners.
macOS Focus settings and notification sound settings apply to system
notifications. Your Mac's output volume applies to all chimes.
5217 prevents idle system sleep while the timer runs, but lets your
display sleep. Manually sleeping or closing your Mac's lid can prevent
an alarm from sounding on time. On wake, the countdown catches up to
the elapsed time; it does not replay old alarms.

TODAY'S TOTAL
Only full, completed 52-minute intervals count toward today's total.
Paused time does not count. Elapsed intervals during manual sleep do
count, since the timer follows wall-clock time. These are timer totals,
not measurements of computer activity.

PRIVACY
No account, ads, or analytics. The app fetches quote batches over HTTPS
from zenquotes.io. No timer history, session data, or personal details
are sent. The service receives normal connection metadata, such as your
IP address. Downloaded quotes are saved locally and work offline.
Clicking a source link opens it in your browser. Timer state and a
month of completed sessions are stored only on this Mac, in:
~/Library/Application Support/5217/timer.json

This is an independently built native Mac app inspired by the requested
52/17 rhythm, and is not affiliated with the referenced Android app.

SOUND STORAGE
The selected-sound preference is saved in:
~/Library/Application Support/5217/sound-settings.json
Prepared notification sounds are stored locally in ~/Library/Sounds
with a 5217- filename prefix. Apple audio is read from your Mac and is
not distributed with this application.
